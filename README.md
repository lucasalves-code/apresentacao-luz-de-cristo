# A Luz de Cristo - Apresentação Interativa

Apresentação interativa desenvolvida em HTML, CSS e JavaScript voltada para sala de aula e estudos.

## 📋 Funcionalidades

- **Painel do Professor (Controle)**: Navegue pelos slides com controle ativo.
- **Modo Aluno (Acompanhar)**: Interface adaptada para os alunos visualizarem e acompanharem o conteúdo.
- **Totalmente Standalone**: Não depende de bibliotecas externas pesadas; roda diretamente em qualquer navegador moderno.

## 🚀 Como executar localmente

Basta abrir o arquivo `index.html` em qualquer navegador web (Chrome, Edge, Firefox, Safari).
